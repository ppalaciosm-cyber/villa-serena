# Villa Serena — Sistema de Gestión Hotelera

Proyecto universitario (UMG, 8vo ciclo, Desarrollo Web). Sistema completo para un hotel con módulos de administración, recepción, limpieza, mantenimiento, room service y portal del huésped.

## Estructura
- `apps/web` — Frontend web (React 19 + Vite + TypeScript + Tailwind v4)
- `apps/api` — Backend (NestJS + Prisma + PostgreSQL)
- `apps/mobile` — App móvil del huésped (React Native + Expo, fase posterior)
- `packages/shared` — Tipos, esquemas Zod y constantes compartidas
- `packages/config` — Configuración compartida de ESLint y TSConfig

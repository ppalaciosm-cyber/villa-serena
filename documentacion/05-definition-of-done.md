# Definition of Done

Una historia de usuario está **terminada** cuando:

- [ ] El código está en `develop` mediante PR revisado por al menos 1 compañero.
- [ ] Pasa lint, typecheck y tests en CI.
- [ ] Endpoint documentado en Swagger (si aplica).
- [ ] Vista funcional conectada a la API real (no datos mock), si aplica.
- [ ] Validaciones en front y back.
- [ ] Probado manualmente con el rol correspondiente.
- [ ] Sin errores en consola del navegador ni de la API.
- [ ] Criterios de aceptación de la historia cumplidos y verificados por el PO / Scrum Master.
